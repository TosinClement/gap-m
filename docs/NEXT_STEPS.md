# Next steps after v0.1.0

Status: released 2026-10-05.

- **Second-rater review.** Have one or more independent reviewers (a health system AI governance lead, a security practitioner) rate a stratified sample of links; report agreement and resolve disagreements in v0.2.
- **AI RMF Generative AI Profile (NIST AI 600-1).** Add its actions as a fifth reference layer, with generative-specific monitoring controls (content safety, hallucination tracking).
- **The rest of HTI-1 (b)(11).** Map the feedback (ii)(C), source-attribute access and modification (v), and intervention risk management (vi) paragraphs as elements.
- **Pilot.** Apply the control set to one deployed predictive intervention and record which evidence artifacts already exist, which are missing, and the effort to produce them.
- **NIST OLIR submission.** Package the links in the OLIR template so they can sit alongside NIST's own informative references.
- **Amendment watch.** Re-run the registry step whenever 45 CFR 170.315(b)(11), CPG 2.0, or AI 800-4 changes; publish a diff of affected links.
